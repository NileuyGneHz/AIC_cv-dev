# STORY.md · AIC 视觉逻辑算法应用赛技术文档 PPT

## 受众与目标

- 受众：区域赛（省赛）线上评审评委，2026-11-07~08 评审。
- 目标：证明三件事——
  1. **合规**：自建 Gazebo 数字孪生平台逐条满足官方平台硬指标（对标说明）；
  2. **可靠**：视觉 / 决策 / 控制三段闭环有真实数据支撑（12/12、60 位点 0 误判、落位 0.8 mm）；
  3. **完整**：从识别到抓放再到实时判分可视化，全过程可看、可录、可复现。
- 语气：学术答辩式，证据驱动，结论先行，每个主张配数据或图。
